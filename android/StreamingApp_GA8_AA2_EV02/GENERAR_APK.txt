1. Abra Android Studio.
2. File > Open y seleccione la carpeta StreamingApp_GA8_AA2_EV02.
3. Espere a que termine Gradle Sync.
4. Ejecute la app con el boton Run para probarla.
5. Para generar el APK: Build > Build App Bundle(s) / APK(s) > Build APK(s).
6. El APK queda normalmente en: app/build/outputs/apk/debug/app-debug.apk
